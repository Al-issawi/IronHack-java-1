# Lab: Git Bash 1

Carpeta de práctica: `java\gitbash-1`.

## Qué hice

- `ramas/`: repo Git conectado a GitHub. Subí `main` y `feature/add-rama-page`, hice merge, subí el resultado y borré la rama de característica local y remotamente. Después hice tres commits adicionales, los subí, y restablecí `main` al primero de esos tres commits tanto localmente como en GitHub.
- `reset/`: repo local de práctica con tres commits y reset al inicial; contiene los archivos de log e historial pedidos.

## Archivos solicitados

- `reset/mdaliGitlog.txt`: salida de `git log --oneline` en el estado final de `main`.
- `reset/mdaliHistorial.txt`: salida de `history 50` de Git Bash.
- `ramas/README.md`: pasos y comandos del laboratorio.

## GitHub

[Al-issawi/gitbash-1](https://github.com/Al-issawi/gitbash-1) es público. Su rama `main` contiene la página principal, la página fusionada de característica, el primer commit de reset y la guía del laboratorio. La rama `feature/add-rama-page` se borró después del merge.

Los commits usan el correo noreply de GitHub para no exponer el correo personal.
