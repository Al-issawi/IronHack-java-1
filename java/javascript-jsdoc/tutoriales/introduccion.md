# Introducción a JSDoc

JSDoc permite describir el propósito de un archivo, las variables y las funciones mediante comentarios que empiezan por `/**`.

## Tipos y constantes

Usa `@type` para indicar el tipo de un dato y `@constant` para documentar una constante.

## Funciones

Usa `@param` para cada parámetro y `@returns` para explicar el valor devuelto. Añade `@throws` cuando la función pueda lanzar errores y `@example` para mostrar cómo se utiliza.

Consulta la [guía oficial de JSDoc](https://jsdoc.app/about-getting-started).
